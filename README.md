# exp6

Flutter experiment 6 - a student records app using a local SQLite database (sqflite).

## Use

```
flutter pub add exp6
```

```dart
import 'package:exp6/exp6.dart';

runApp(const StudentApp());
```


## Run in VS Code
1. Open this folder in VS Code (File > Open Folder).
2. Open a terminal and run:  flutter pub get
3. Pick a device (Android phone, emulator, Chrome) from the bottom-right corner.
4. Press F5 or run:  flutter run
